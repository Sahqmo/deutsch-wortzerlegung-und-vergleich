독일어 합성어 상성 진단소


독일어 합성단어 기준으로 한국어/일본어/영어 등에서 비슷하거나 동일한 표현을 끄집어 와서
다른 단어들과는 얼마나 비슷하게 조합되는지, 혹은 아예 같은 조합 논리로 이루어진 정확한 단어가 다른 언어에 있는지 등을 판단하고 그걸 퍼센트 수치로 확인한다.
반쯤 재미로 이용해보면서, 어휘력을 늘릴 때 소소하게 재밌는 사이트가 되지 않을까 싶은 생각에 아이디어 구상함.

===

z.B. Kugelschreiber -> Kugel + Schreib + er

영어: ballpoint pen -> ball + point + pen (유사한 단어 2개 있긴 하지만, point라는 단어가 첨가됨. 엄밀히 따지면 schreiber에는 어원인 schreiben이 들어간 것에 반해 pen은 write와 연관이 없다는 점을 둘 수 있겠음.)
한국어: 볼펜 -> 볼 + 펜 (독일어와 동일한 조합. 하지만 고유어가 아닌 외래어임.)
일본어: ボールペン (한국어와 동일함)

z.B. Abfahrtszeit -> Abfahrt + s + zeit

영어: departure time -> departure + time
한국어: 출발 시간 -> 출발 + 시간
일본어: 出発時間 -> 出発 + 時間

z.B. Näherkommen -> Näher + kommen

영어: approach -> 이 경우엔 독일어에 Annähreung과의 연관성이 좀 더 있을지도?
한국어: 접근 -> 접(잇다) + 근(가까이)
일본어: 接近

===
